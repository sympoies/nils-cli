# nils-cli v1.46.0

## Upgrade notes

- Claude native notices are now enabled by host configuration instead of the environment of the
  shell that runs `agent-session restart` or `resume`. On hosts that use Claude native notices, set
  `claude_native_notice = true` in the shared operator rules, keep the daemon notice-writer gate
  enabled, and restart Claude sessions to apply. Without the setting, restart and resume report the
  module as not attached with the reason (#4194, #4186).
- Update `agent-hook` together with the runtime kit that registers the new `remote-ssh-advisory`
  handler; older `agent-hook` builds refuse that handler id (#4208).

## New features

- `forge-cli pr reopen <number> --expected-head <sha>` reopens a closed pull request on GitHub or
  GitLab, checks the head before and after, and reads back the open state (#4182).
- `agent-session delete --if-idle` can retire running managed Claude sessions. It requires settled
  hook state, fresh native idle reports, an empty composer before and after the final idle query,
  and no attached tmux client (#4183).

## Behavior changes

- Version preparation and release publication require a curated `docs/releases/vX.Y.Z.md` with an
  `## Upgrade notes` section (#4189).
- Authenticated board reads verify against the committed registry snapshot first and no longer take
  the exclusive registry lock, which removes a common source of `coordination-lock-timeout` under
  load (#4197).
- Test changes confirmation mismatches name both generator versions and the re-preview recovery
  (#4193).
- Local checks refuse unsupported Bash versions before they start (#4165).
- Declared test scopes admit additive coverage without extra evidence (#4137).

## Fixes

- `forge-cli` paginates issue reverse references to completion; `limited` is set only for an
  explicit caller limit (#4192).
- `test-first-evidence` keeps later gap declarations (#4166).
- `agent-session` keeps the first Console attestation refusal (#4159).
- Test fixtures are isolated from inherited host Git and runtime settings, with a counted audit for
  new bypasses (#4190, #4203, #4204, #4205, #4167, #4163, #4178).

## Limitations

- Idle Claude retirement is best effort: a client that attaches and types in the short interval
  between the final client check and teardown is not fenced.
- The pull request agent-session tempdir probe (#4175) runs on pull request heads only; merge groups
  report it as skipped.
