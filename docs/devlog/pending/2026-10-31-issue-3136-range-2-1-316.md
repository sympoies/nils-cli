## 2026-10-31 - Raise the tested Claude Code range to 2.1.316
<!-- devlog-id: 2026-10-31-issue-3136-range-2-1-316 -->

### Result

- The native notice module now mounts on Claude Code 2.1.296 through 2.1.316,
  so sessions launched or restarted on 2.1.316 attach it instead of recording
  notice-native-version-unsupported.

### Why / context

- Claude Code updated past the previous upper bound (2.1.314) on development
  and service hosts. The range is raised only with evidence on the exact
  release, as the spec requires.

### Evidence

- On an integrity-verified official 2.1.316 the module call-shape scan and
  claude plugin validate pass with the same hooks, API calls and environment
  access as 2.1.314. A native five-step run on 2.1.316 passed: fresh launch
  mounted the module, a notice after a turn was delivered as a
  plugin-attributed row with zero Enter presses and a repeated key was refused,
  a restart delivered a fresh-key notice, and a gate-off launch recorded
  writers-disabled. Before the change the 2.1.316 launch case mounted no
  module.
