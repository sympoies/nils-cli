## 2026-11-13 - Rust toolchain bump to 1.100.0
<!-- devlog-id: 2026-11-13-issue-3624-toolchain-1-100-0 -->

### Result

- rust-toolchain.toml and every workflow toolchain step now pin Rust 1.100.0,
  the stable release of 2026-11-09, in one PR; the toolchain pin audit passes
  on the new value. Linux clippy needed no lint fixes. The bump runbook now
  states which gates run on the PR head and which run in the merge group and on
  main after the merge.

### Why / context

- The pin had held CI on 1.99.1 since a floating stable moved to 1.100.0 and
  exposed macOS-only lints and the Cargo 1.100 test layout; both are fixed on
  main, so the pin can move on purpose. macos_clippy runs only in merge groups
  and full_validation only on main, so neither can run on a PR head; the merge
  group proves macos_clippy before landing and the manual full run on main
  follows the merge.

### Evidence

- Pin audit on 1.100.0; clippy with all targets and features and -D warnings on
  1.100.0; local-fast passed 10843 tests (one retried flaky agent-session
  admission test).
